# 🍪 SweetCrust Cookies
SweetCrust Cookies is an online cookie shop website based on the SweetCrust Cookie Shop Management System. It provides a simple and interactive interface for customers to browse cookies, customize gift boxes, manage their cart, place orders, and track or cancel orders.

## ✨ Features
- 🍪 Cookie Catalogue
- 📖 Detailed Cookie Information
- 🎁 Customizable 3, 6 & 12 Cookie Gift Boxes
- 🛒 Shopping Cart
- 🎟️ Coupon Code Support (`SWEET10`)
- 🧾 Checkout & Order Placement
- 📍 Order Tracking
- ❌ Order Cancellation
- 📧 Newsletter Subscription
- 📱 Responsive Design

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Font Awesome
- Animate.css
- Google Fonts
- LocalStorage

## 🎯 Purpose
The website provides a digital interface for the SweetCrust Cookie Shop, making it easier for customers to explore products, customize orders, and complete the ordering process.

## 🚀 How to Run
1. Clone or download the repository.
2. Open the project folder in VS Code.
3. Open `index.html`.
4. Run it using Live Server or open it directly in a browser.
